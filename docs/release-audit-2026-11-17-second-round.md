# Дополнительный голос с сохранением результатов — 17 ноября 2026

По прямому запросу владельца текущий конкурс получает второй раунд голосования. Каждый браузер, голосовавший ранее, может отправить ещё один бюллетень. Повторный бюллетень в текущем раунде запрещён. Старые записи остаются принятыми и продолжают участвовать в общем подсчёте.

## Реализация

Добавлен неизменяемый через обычную форму номер `Contest.voting_round`. Миграция `voting.0008` единожды переводит текущий простой конкурс `promtour` из первого раунда во второй. Повторная публикация приложения не увеличивает номер. Редакторский текст правил обновляется только при точном совпадении с прежним стандартным текстом.

При проверке повторов защищённые идентификаторы браузера и сети вычисляются в пространстве текущего раунда. Для первого раунда используется прежний алгоритм, совместимый со всеми существующими бюллетенями. Поля, хеши, статусы, даты и выбор в старых бюллетенях не меняются; ограничения уникальности PostgreSQL сохраняются и не позволяют записать два бюллетеня того же браузера в текущем раунде. Лимит общего IP остаётся отключённым для текущего конкурса, как в предыдущем исправлении. Cookie браузера и ключи доступа к регистрациям не сбрасываются.

`stats_payload` по-прежнему суммирует все принятые бюллетени, поэтому старые и новые голоса учитываются вместе. Функция отмены/сброса бюллетеней не вызывается. Номер текущего раунда виден в карточке конкурса только для чтения. API сообщает номер раунда, страница объясняет открытие нового этапа и сбрасывает состояние завершённого экрана при смене раунда в загруженной версии скрипта. Уже открытые старые страницы следует обновить.

## Проверка

95 автоматических тестов прошли. Новые сценарии подтверждают повторный голос со старым cookie после смены раунда, запрет третьего голоса, неизменность всех полей и выбранных вариантов первого бюллетеня, суммирование старых и новых результатов, раздельные сетевые ограничения по раундам. В PostgreSQL восемь одновременных запросов из того же браузера принимают ровно один дополнительный бюллетень.

В Chrome/Playwright на локальной копии один браузер прошёл первый раунд, получил запрет повтора, после открытия второго раунда проголосовал ещё раз и снова получил запрет следующего повтора. Тестовые бюллетени не отправлялись на рабочий сайт. Перед выпуском сохранены отдельный dump PostgreSQL, исходники и штатная прикладная копия. Каталог редактора повторно не импортируется.
