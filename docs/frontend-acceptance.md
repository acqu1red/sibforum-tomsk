## 6. Выделение админки на отдельный поддомен

Реализован отдельный вход **`admin.sibforum-tomsk.ru`** (локально `admin.localhost`) без публичной страницы авторизации на сайте форума:

- `accounts.middleware.Admin2FAMiddleware` разрешает `/admin/` и `/api/v1/admin/` только на разрешённых `ADMIN_HOSTS`; на основном домене возвращается 404, а не редирект на admin-поддомен.
- `ADMIN_SITE_URL` используется в QR чек-ина. `PUBLIC_SITE_URL` по-прежнему ведёт на личную страницу участника.
- Пароль и TOTP остаются обязательными. Существующий QR на `/admin/2fa/setup/` совместим с Google Authenticator, Microsoft Authenticator и Яндекс.Ключом. Отдельный Google OAuth не нужен.
- POST `/admin/login/` ограничен 20 попытками на IP за 10 минут, затем возвращается 429. TOTP запрещает повторное использование кода и блокируется после пяти ошибок.
- Admin-сессия — 30 минут с продлением при активности, host-only cookies без общего `Domain`.
- `client_ip` использует `X-Real-IP` только при явном доверии к proxy-заголовку; Nginx перезаписывает его адресом клиента. Доверие к произвольному `X-Forwarded-For` не включено.
- Nginx на публичном домене возвращает 404 для `/admin/` и staff API. На admin-домене `sitemap.xml` возвращает 404, `robots.txt` — `Disallow: /`, `X-Robots-Tag` — `noindex, nofollow, noarchive, nosnippet`.
- IP-whitelist не используется: он несовместим с VPN. Скрытие адреса и запрет индексации не заменяют авторизацию.
- Общий SAN-сертификат выпускается для `${DOMAIN}` и `${ADMIN_DOMAIN}` и используется обоими HTTPS virtual hosts.

Локальный вход: `http://admin.localhost:8100/admin/`. Production-like: `http://admin.localhost:8101/admin/`.

Проверено:

- основной хост `/admin/` и staff API — 404;
- admin-хост `/admin/` — 302 на вход, staff API без авторизации — 401;
- `sitemap.xml` на admin-хосте — 404, `robots.txt` и `X-Robots-Tag` присутствуют;
- реальный TOTP, ограничение перебора после 20 попыток, доверенный proxy IP;
- отдельный HTTPS Nginx на 8443: основной `/admin/` — 404, admin `/admin/` — 302, `robots.txt` — 200 с запретом индексации;
- `nginx -t` и `docker compose -f docker-compose.prod.yml config --quiet` проходят.

Тестовый Nginx и самоподписанный сертификат удалены. Тестовые администраторы и записи login rate limit очищены. Публичный sitemap отсутствовал и не изменялся; admin-URL в него не добавляются.
