# Исправление выбора в голосовании — 17 ноября 2026

На рабочем конкурсе в новом изолированном Chrome все 84 переключателя были отключены, форма отправки скрыта, а интерфейс утверждал, что пользователь уже проголосовал. Конкурс был открыт по расписанию, глобальная публикация голосования включена. Причина: настройка «Бюллетеней с одной сети» равнялась 1; первый голос с общего IP блокировал других людей за тем же офисным, Wi-Fi или операторским NAT. Проверка нового браузера также возвращала `already_voted: true`.

Добавлено значение 0 для отключения общего лимита по IP. Запрет повторного бюллетеня того же браузера сохраняется в приложении и ограничении PostgreSQL; ограничения частоты запросов и числа вариантов в номинации не меняются. При общем IP каждому бюллетеню назначается отдельный сетевой слот, поэтому существующая уникальность слотов сохраняется. Миграция меняет только известную старую настройку текущего конкурса `promtour` с 1 на 0 и стандартный текст правил, если он не изменён редактором. Другие конкурсы, кандидаты, бюллетени и голоса не переписываются.

В панели добавлено пояснение к значению 0. На публичной странице убрано неверное описание общего ограничения сети; сообщение о принятом бюллетене говорит о браузере.

92 автоматических теста прошли. Новые сценарии проверяют два браузера за одним IP, сохранность ранее принятого сетевого бюллетеня и отказ повторному голосу из того же браузера после смены IP. В Chrome/Playwright на локальной копии два независимых браузера из одной сети выбрали участника нажатием «Выбрать» и отправили бюллетени; после обновления первого браузера повторный голос недоступен. Проверка выполнена на ширинах 1440 и 390 px. Тестовые голоса на рабочий сайт не отправлялись.

До обновления сохранены независимый dump PostgreSQL, исходники и штатная прикладная копия. Публикация выполнена штатным скриптом с применением миграции `voting.0007`; данные редактора не импортируются повторно.
