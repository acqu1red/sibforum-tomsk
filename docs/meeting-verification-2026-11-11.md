## Что проверено

- 35 тестов Django на PostgreSQL: права руководителя, публикация контента, варианты фото, CSRF, лимиты, одновременное голосование, ручной сброс, MIME-письма с русским текстом и PDF, ошибки почтового провайдера и приватные ссылки S3.
- Сквозные действия в настоящих формах локальной админки: изменение текста и автоматическое обновление открытой страницы, общая и отдельная фотография с фокусом, логотип и галерея кандидата, сохранение выбора, голосование, повтор с новым браузером из той же сети, подтверждённый сброс, предпросмотр регистрации.
- Chromium и WebKit: по 72 проверки на ширинах 320, 360, 390, 768, 1024 и 1440 px. Меню, возврат фокуса, Escape, круги, восемь номинаций, максимум три выбора, модальные карточки, отсутствие горизонтального переполнения и ошибок JS. Повторено со сборкой, загружающей изображения из настоящего Object Storage.
- 206 встроенных изображений перенесены в бакет. Реальная загрузка оригинала через Django Storage создаёт три WebP-варианта (160/400/960); проверены размеры, публичное чтение производных и отказ в чтении оригинала без подписанной ссылки.
- Домен Postbox имеет статус DKIM Success. Письмо из Django принято сервисом; владелец подтвердил доставку во «Входящие» Яндекса.

## Ограниченные ресурсы

Один Chromium внутри Docker с жёстким лимитом RAM, `memory-swap` равным этому лимиту (без swap), CPU контейнера 1. Дополнительно CDP замедляет CPU и сеть. Профили и воспроизводимая процедура находятся в `tools/performance/measure.cjs`. Кэш браузера отключён. Каталог обслуживается локальной тестовой системой, изображения загружаются из реального бакета. ## Практические ограничения

- У Postbox стартовая квота 200 писем/сутки на всё облако; для массовой регистрации её нужно увеличить.
- Защита голосования ограничивает повторы по сети и браузеру; общий Wi-Fi разделяет лимит, смена сети не позволяет гарантировать один голос на человека.
- Новые фото, утверждённые логотипы спонсоров, окончательные тексты и лоты заполняет организатор. Внешний исторический сайт не входит в этот репозиторий.
- Нагрузочный сценарий на 500 одновременно регистрирующихся пользователей и реальные устройства на площадке в этот отчёт не включены.

## Рабочий сервер

Проверены главная, конкурс, включённая регистрация, отложенный виджет CAPTCHA, вход `director` по паролю без TOTP и четыре предпросмотра фотографий. Ошибок JS и HTTP-ошибок изображений в проверенном сценарии нет. Django `check --deploy --fail-level WARNING` проходит. Nginx и HTTPS работают; старый `/promtour/` перенаправляет на главную. На VPS проверено чтение Object Storage и отправка тестового кода через Postbox.

Перед миграциями сохранены исходники, env и резервные копии вне VPS. После миграций: 1 форум, 19 событий, 13 спикеров, 0 заявок и 0 бюллетеней. Тестовые голоса и фотографии проверялись в изолированной системе. Все 206 публичных объектов сверены по размеру и SHA256; постоянные копии `site/img` удалены с VPS после проверки резервной копии. Ежедневная резервная копия БД и опись S3-версий созданы успешно.
