# Источник логотипов

Перенесены по поручению владельца из видимых блоков «Организаторы форума» и «Промтуризм в Томске» сайта https://promtour.tomsk.siberianforum.ru/, связанного с https://siberianforum.ru/. Исходные изображения сохранены без перерисовки. URL каждого файла — в deploy/reference-logos.json. У ТПП использован обычный белый вариант из последнего блока, без старой юбилейной надписи «30 лет».
